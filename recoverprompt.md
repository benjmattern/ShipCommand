# Recovery Prompt

Use these steps to recover or continue working on the project locally.

## Prerequisites
- Install Node.js and npm.
- Open the repository folder in VS Code.

## Common commands
- Install dependencies: npm install
- Start the dev server: npm run dev
- Build the app: npm run build

## If the environment is missing Node.js
- Install Node.js from the official website or through winget.
- Reopen the terminal after installation so the PATH updates.

## If the app fails to start
- Confirm dependencies were installed.
- Confirm the current directory is the repository root.
- Check the terminal output for missing packages or TypeScript errors.
