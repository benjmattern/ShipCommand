# Status

## Current state
- Repository initialized with a local Vite + React + TypeScript + Tailwind scaffold.
- A basic unified data preview UI is in place for three starter sources: Excel, SharePoint, and ServiceNow.
- Shared connector and type modules now exist to support a source-agnostic data layer.
- Documentation now reflects a local-only proof-of-concept approach with no public frontend and no commitment to a backend database structure yet.
- Development will rely on Excel files and exported data to simulate source content until external testing environments are available.

## Next steps
1. Continue local development and validation of the UI and connector patterns.
2. Keep the backend design intentionally flexible and avoid locking in a database choice prematurely.
3. Add sample data adapters for Excel-based and exported file workflows.
4. Prepare for later API integration work while keeping the current local-first development model intact.
